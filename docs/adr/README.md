# Architecture Decision Records

Use an ADR for architectural decisions that are significant, cross-cutting, or
difficult to reverse. Copy `template.md`, assign the next four-digit number, and
use a short kebab-case title, for example:

```text
0001-otlp-signal-selection.md
```

An ADR starts as `Proposed`. Change it to `Accepted` only after human review.
Accepted ADRs take precedence over tentative proposals in the implementation plan
and prototype document. Superseded decisions remain in the repository and link to
their replacement.
