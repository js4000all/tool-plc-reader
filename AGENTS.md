# Development Guidelines

- Implement the PLC Reader in Go.
- Prefer simple, idiomatic Go code.
- Avoid unnecessary abstractions.
- Keep PLC communication separate from data processing.
- Add tests for important behavior.

## Design References

- `docs/plc-reader-prototype.md` contains the initial
  requirements, architecture, and unresolved design decisions.
- Read this document before proposing or implementing
  architectural changes.
- Do not treat tentative proposals as finalized requirements.
